## Case 20: 5/22 vs 5/25 同日兩篇 Mode C 效應對比 — R29 推出依據（v0.8.7）

**5/22 同日兩篇（F22 + F23）vs 5/25 同日兩篇（F20 + F21）對照**：

| 維度 | 5/22 同日 | 5/25 同日 |
|---|---|---|
| 兩篇觀眾合計 | **15,872** | 1,461 |
| 兩篇非追蹤者 % | **91.5% / 94.5%** broke 雙篇 | 16% / 24.7% 雙鎖鐵粉 |
| 主題類別 | **相關**（AI 視頻 / 角色一致性 niche）| 分散（哲學 + dev ship）|
| framing 互補 | ✅ vulnerable vs insider | ❌ 故事 vs 答疑 但 audience 重疊低 |
| 互相效應 | **互相強化**（兩篇都 broke 90%+）| **沒累積**（兩篇都鎖鐵粉）|

**5/22 配對成功因素**：
- F22 (vulnerable confess) + F23 （insider 行業洞察） = 同 niche（AI 視頻）+ 不同 framing 角度
- audience overlap 但 emotional hook 互補
- 演算法判「同 niche 連動內容」雙 broke

**5/25 配對失敗因素**：
- F20 （個人故事 / 鐵粉圈） + F21 （dev ship / 工具圈） = audience bucket 完全分散
- 沒有 audience 累積效應
- 兩篇各自鎖在自己鐵粉圈

→ **R29 推出**：Mode C 同日連發**配對要選同 niche + 互補 framing**。

### Mode C 同日配對推薦表

| 配對 | 預期等級 |
|---|---|
| F22 + F23 | ⭐⭐⭐⭐⭐ 互強 broke 鐵粉圈雙篇（5/22 實證）|

| F23 + F21 同 niche | ⭐⭐⭐⭐ |
| F21 + F20 分散 | ⭐⭐ 弱（5/25 實證）|
| F20 + 任何 | ⭐⭐ 弱（個人故事 audience 太窄）|
