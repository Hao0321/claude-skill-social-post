## Case 47: 2026-08 Thread「不要再訂閱什麼自動剪輯了」— F19 + 樓中樓連結變體，9h 衝 9.3 萬 🆕

**內容（F19 極簡版）**：「不要再訂閱什麼自動剪輯了，我已經開源了！！而且我還在持續更新你們要的功能我都會加上去」

**戰績（9 小時）**：9.3 萬瀏覽 ／ 讚 1,543 ／ 留言 82 ／ **轉發 203** ／ **分享 993**。

**🆕 樓中樓第二則掛 GitHub 連結**：148 讚 ／ **轉發 21** ／ **分享 218** —— 卡片顯示 repo **2k stars ／ 269 forks ／ 3 contributors**（⚠️ 卡片是概數；repo ＝ 自動剪輯 skill video-autopilot-kit，2026-08-04 GitHub 查核實際 **1,693 stars ／ 278 forks**）。

**三個 learning**：

1. **🆕 樓中樓連結 = 繞過 R25 又能導流的解法**：正文維持零連結（R25 合規），連結放在自己回覆的第二則。第二則的**分享 218 高過它自己的轉發 21（10 倍）** —— 有一群人是專門為了「把 repo 傳出去」而分享，不是為了表態。**這是目前最漂亮的一次「不降權導流」。**
2. **真 KPI 落地：自動剪輯 repo 星數 1,693 ／ forks 278**（2026-08-04 GitHub 查核；卡片顯示的 2k 是概數）。對照 FB 端 7/20 那篇四萬瀏覽只換到 **2 個連結點擊** —— **Thread 才是導流引擎，FB 收信任與觸及**（呼應 R23 的 FB vs Thread 分工）。
3. **極簡 F19 仍有效**：全篇兩句、無 artifact 綁定（只說「已經開源了」），9h 即 9.3 萬 ／ 分享 993。⚠️ 但轉發僅 203（轉發率 0.22%），低於綁 artifact 版的 0.25%，符合 R19① 抽象 stance 轉發有天花板。
