## Case 12: 2026-05-16 F4 in Thread 反面教材 — Claude Code 社群 3786 里程碑（v0.8.2 patch 基礎）

**內容**：「Claude Code 社群創建 1 個月，社群人數來到 3786 人！！！真的是一個里程碑，歡迎更多想要學習各種 AI 的朋友一起加入！！我有一堆免費工具開源給你！！」

**戰績**：

- 觸及只剩 25/7 同帳號 F19 爆款的 3-5%

### 失敗診斷（6 個 F19 元素缺 4 個）

| F19 元素 | 這篇 | 結果 |
|---|---|---|
| 1 段不換行 | ✅ | OK |
| sentence 2-5 句 | ✅（3 句）| OK |
| ！最多 2 個 | ❌ 開頭「！！！」 | **違反 v0.8.1 排版鐵則** |
| 敵人 / 英雄敘事 | ❌ 純宣告 | **缺**|
| TM 級用詞 | ❌ | **缺** |
| 攻擊性動詞 | ❌ | **缺** |
| 純粹動機 framing | ❌ | **缺** |

→ **這篇是 F4 公式（FB 鐵粉社群 engagement）誤搬到 Thread**。

### 核心 lesson：F4 / F1-F18 都不適合 Thread

| 公式 | 設計平台 | Thread 適配 |
|---|---|---|
| F1 Day-N 開發日誌 | Threads（原設計）| ✅ |
| F4 社群里程碑+投票 | FB | ❌ **無對立 = 無轉發** |
| F6b 純血 hype | FB | ❌ ！！！ 太多 + 太長 |
| F14 演講濃縮 | FB | ❌ 太長 |
| F15 mini | FB | ❌ 結構不符 |
| F16 精選彙整 | FB | ❌ bullet list 不符 |
| F18 AIGC Reels | FB+IG | ⚠️ Reels 可，純圖不行 |
| **F19 立場宣言** | **Thread** | ✅ **唯一原生 Thread 公式** |

→ **Thread 只能用 F19**（或 F7 POV 吐槽變體），其他公式直接搬 = die。
