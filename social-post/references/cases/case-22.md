- **編號 numbered list**（Mode C 第一次用）

- 大方否認誤解（沒賣課 / 沒接案）
- 直接告知期待（追蹤就好 / 來社群）

### voice 鐵則（跟其他 Mode C 不同）

- 無「！」hype
- 無 TM 級用詞
- 無攻擊性動詞
- 用「── 真的沒有 / 真的不是」溫和強調
- 每點開頭直接 numbered（一、二、三、四、五）
