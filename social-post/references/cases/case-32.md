### 🏆 學習 1：superlative 權威宣稱 = milestone broke 放大器

| | 5/28 F25b（Line 5000）| 6/14 F25b（台灣最大）|
|---|---|---|
| milestone | 純數字（5000）| **「台灣最大」superlative** |
| 觀眾 | 852 | **3,079（3.6x）**|
| 非追蹤 | 16.7%（鎖鐵粉）| **57.9% broke**|

→ 同樣 F25b 集體歸功，加「全台第一 / 最大」superlative 權威宣稱，**非追蹤 3.5x**。「第一」會自己長腳，路人也想看「台灣最大的長怎樣」。

### 🏆 學習 2：giveaway campaign 的 funnel 收割（R7 飛輪閉環）

6/9 mega（42K / 959「Discord」留言）+ 系列 drop → Discord **6,930 → 8,887（+1,957 / 2 週）**= 台灣最大。**R7 真 KPI 完整閉環**：FB viral → keyword CTA → Discord 集合 → 台灣最大社群 milestone → 再發 milestone 文再 broke。飛輪轉起來了。

### 學習 3：F25b 即使 Reel 格式 text 仍帶得動

排名 3/10 Reel，57.9% broke ── 強 F25b text（milestone + superlative + 集體）carry 過 Reel 格式弱點（vs 6/8 串燒 Reel hype+GitHub = 16%）。**內容 > 格式**再驗證。
