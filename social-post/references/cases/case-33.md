## Case 33: 2026-06-11 同日 A/B — 抽象 claim（15.1%）vs 具體 demo（68%）：demo > claim（v1.0.1）🏆

**同日同帳號兩篇，giveaway/skill 主題，唯一變數 = 抽象宣稱 vs 具體 demo**：

| | A 網紅製造機（10:46）| D 自動剪輯 demo（15:12）|
|---|---|---|
| 框架 | 抽象「我 skill 讓人變網紅」| **具體「Claude 操作 CapCut 自動剪片」+ 留言區成品** |
| hook | 自證社會證明 | **Fable 5 news（燒 60 鎂優化）+ 可驗證成品** |
| 觀眾 | 2,153 | **7,584（3.5x）**|
| **非追蹤** | **15.1% 鎖鐵粉** | **68% broke** |
| 留言 | **91**（R35「我要」）| 24 |
| 儲存 | 20 | **45** |
| Reel 排名 | 5/10 | **1/10** |

**A**：「很多人叫我網紅製造機，社群夥伴拿我 skill 經營自媒體流量暴漲...留言『我要』連結放留言區...醜話講前面要準備 Claude Code Max」
**D**：「昨天 Fable 5 一出我馬上開 Ultracode 燒 60 鎂優化自動剪輯 skill...別的剪輯給你介面自己剪，我這個讓 Claude 直接操作 CapCut...只給素材+錄音檔，剪輯字幕轉場全自動...留言區那支就是它剪的...今晚 Discord 分享會」

### 🏆 學習：具體 demo + 看得到的成品 >> 抽象宣稱（demo > claim 鐵律）

- 同日、同帳號、同 skill 主題 → 唯一變數 = 抽象 vs 具體
- A 抽象「相信我很強」= 鐵粉狂留言（91「我要」）**但路人無感 → 15.1% 鎖鐵粉**
- D 具體「看，這支是 Claude 剪的」+ 可驗證 + news hook → **68% broke + 45 儲存**
- **comments ≠ broke**：A 留言 4x D，broke 卻只 D 的 1/4 ── 演算法 broke 看「內容值不值得給路人」（D 的 demo + 45 儲存 R18）不是留言數
- **鐵律**：給路人「看得到、能驗證」的成品，不是「相信我很強」的宣稱
- D 還疊 Fable 5 news hook（「燒 60 鎂」具體投入 = 誠意 + 好奇）
