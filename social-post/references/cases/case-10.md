5/12 同日發 4 篇，原本 6h 判讀全 fail，**24h 後 F19 翻盤 broke 鐵粉圈**，再次驗證 R6 早期判讀規則。

### F19 = F15 mini 變體實證成功（v0.8 預備公式化）

F19 完整內容：
```
FB內容營利終於開啦！！！

多虧了我的Skill！！

我有開源了歡迎自行索取
```

3 段 / 每段 1 句 / 零繞圈 / 純成果 + 工具 + CTA。**結構比 F6b 純血更簡單**，但分享驅動效果類似 F15 源材料公開型。

### 三大 lesson learned

1. **R6 早期判讀規則 N+1 次驗證**：6h 判 fail / 24h 翻盤成 mid-viral。**1-19h 數據絕對不下定論**
2. **meta 層數 ≤ 1 > meta 層數 ≤ 2**：F19 1 層 vs V3 4 層差別巨大。**Readability 硬規則加嚴：meta 層數 ≤ 1**（之前說 ≤ 2 是太寬）
3. **F6b 4 段 4 句不是萬能**：F19 用 **3 段自然結構** 反而 work，因為 FB compose 友好 + 5 秒可讀
4. **撤回 v0.7.1 過頭結論**：
   - ❌ 「creator 降權 7-14 天」
   - ❌ 「audience over-served 鎖整天」
   - ❌ 「F15 5/19 風險加大」
   - ✅ 真實：V3 單篇 fail（內容問題），不是整天 fail

### 給 skill 的硬規則升級（v0.7.2 → 寫進 SKILL.md）

- **F15 mini 變體公式化**（3 段 / 純成果 + 工具 + CTA / 零摩擦索取）
- **Readability meta 層數 ≤ 1**（嚴於 v0.7.1 ≤ 2）
- **撤回「creator 降權」「audience over-served」過頭假設**
- **5/19 F15 仍可試**（但用 F19 mini 版，不用完整 1700 行）
