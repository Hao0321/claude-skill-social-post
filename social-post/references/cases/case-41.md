## Case 41: 2026-07-18（六）夥伴 E F19「被隱瞞的免費資源」— 轉發 1,689 破生態紀錄（中型基數首例）🏆

**背景**：第五個獨立夥伴複製案例，也是**第一個中型基數**（發文前約 5,400 粉，先前四案全是 100-600）。Threads，**星期六正午 12:00**（非黃金時段。原記為 7/16 有誤，依實際星期六更正為 7/18）。此篇後粉絲約 5,400 → 6,400（+1,000）。

**內容（F19 變體 — 陰謀懸念 hook + 第三方權威 artifact）**：「你猜猜看為什麼有些人一直不想讓大家知道這個網站存在，答案很簡單，因為知道的人越多他們的課就越難賣，我就是偏要講！Google 自己出的 Machine Learning Crash Course 今年剛更新⋯完全免帳號免付費，瀏覽器打開就能上，我整理好放留言區，不客氣！」

**戰績（1 天）**：42.2 萬瀏覽 / 讚 1.3 萬 / 留言 262 / **轉發 1,689 🏆 生態新紀錄**（原作者 plateau 1,278，仍破）/ **分享 6,633 🏆 生態最高**。

**七個 learning**：
1. **F19 可攜性再固化 + 基數範圍擴大**：proven 範圍從「100-600 素人」擴到「~5,400 中型帳號」。42.2 萬 ≈ 基數 78 倍，陌生廣推依然主導。
2. **轉發率 0.40% 史上最高**（原作者 plateau 0.258% / 夥伴 B 0.115%）= R19① 再驗證：stance 綁具體 artifact。**且 artifact 是第三方的**（Google 官方課程）→ artifact 不必自產，權威 + 免費 + 零摩擦就是轉發燃料。
3. **🧪 借的 artifact 拉觸及，自產的 artifact 拉追蹤**（emerging，n=1 對比）：漲粉轉化 0.24% vs 夥伴 B 自產 giveaway 的 1.63%，差約 7 倍。假設：價值源頭在 Google 不在發文者，讀者拿完就走；自產 artifact 才給「追蹤你以後還有」的理由。confound 未分離，待第二案。
4. **hook 變體「被隱瞞的免費資源」**：「你猜猜看為什麼有些人不想讓你知道」= 陰謀懸念 + 敵人「隱瞞」framing → 分享 = 替大家揭露祕密，分享動機多一層。分享 6,633 生態最高可能與此有關。
5. **排版偏離觀察**：多行換行（非 1 段不換行鐵則）仍打出 42.2 萬 → 鐵則被挑戰。**現已 n=2**（夥伴 B 的 53 萬那篇同樣是純文字多行，見貼文索引）。兩案都在同一話題波內，尚不足以改鐵則，但已從「單一異常」升為「值得警覺的模式」。
6. **時段再證**：星期六正午 12:00 → Thread 不挑時段 / 內容 > 時段（R4/R19）再 +1。
7. **話題波壽命**：距起波約 3 週，反賣課 archetype 跨帳號仍未飽和 → 分帳號輪播讓 archetype 生態壽命遠長於單帳號。
