## Case 37: 2026-06-26 「夥伴拿它一篇衝 17.4 萬」第三方戰績 social proof — broke 25K / 83.3%（v1.0.2+）🏆

**內容**（R34 ，、 + ──，第三方戰績 + 謙卑 + 開源 giveaway）：「昨天那套演算法 skill 又搞出誇張成績 ── 社群夥伴拿它在 Thread 發一篇，瀏覽衝 17.4 萬，粉絲從一百多變四千六百多...老實說這套我沒辦法教你怎麼做，花快三個月一篇篇磨出來的直覺，寫不成 SOP...所以我給的不是一堂課，是直接開源丟給你...連結放留言區拿去用就好，不用留言跟我要，覺得有用順手 GitHub 點顆星」

**戰績（plateau）**：
- 觀眾 ~25,079 / **非追蹤 83.3%（20,885）** broke
- 讚 191 / 留言 48 / **分享 53** 🔥（分享 = 20x 權重，最強信號）
- 年齡 35-44 (43.1%) / 45-54 (28%) / 25-34 (20.9%)
- 連結放留言區（R25 合規）

### 🏆 學習 1：第三方「具體戰績」social proof = 強 broke + 高分享

對比 Case 33（6/11 網紅製造機）：

| | 6/11 網紅製造機 | 6/26 第三方戰績 |
|---|---|---|
| social proof | **抽象**「很多人用我 skill 變網紅」| **具體**「夥伴一篇衝 17.4 萬 / 400→4,600」|
| 非追蹤 | 15.1% 鎖鐵粉 | **83.3% broke** |
| 分享 | 15 | **53** 🔥 |

→ 同樣「別人用我的東西」intent，**抽象 claim 鎖鐵粉，具體第三方戰績 broke 25K**。「它對別人也有用 + 一個誇張數字」比「我很強」可信 + 可分享。**concrete > abstract 再驗證，且「works for others」> 「I'm great」**。

### 🏆 學習 2：「我沒辦法教你，直接開源丟給你」= 謙卑 + 價值 + giveaway

「花三個月磨的直覺，寫不成 SOP，所以我給的不是課，是開源」= **謙卑抬高價值 + 反賣課 giveaway** = trust + 高分享。53 分享 = 「works-for-others + 免費 + 誠實」三合一最 shareable。

### 學習 3：CTA 降到最低摩擦也能 broke

- 這篇**沒用 R35 keyword CTA**（「不用留言跟我要」），改「連結放留言區拿去用 + 順手點星」
- 留言 48（低於 keyword-CTA 篇）但 **分享 53 + broke 83.3%** = 內容夠強時，分享會自己帶，不靠留言磁鐵

→ **F28 候選：第三方戰績 social proof 型**（秀一個具體的、他人用你的東西做出的誇張成績）。
