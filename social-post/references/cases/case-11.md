### 3 篇共通 F19 公式

```
[敵人 + 我對立 hook]
[攻擊性宣言 + 行動]
[純粹動機 + 零代價聲明]
```

**演算法 trigger 分析**：

1. **Thread 轉發權重 = 最強信號**（vs FB 私訊分享）— 3 篇都有 10-76 轉發 = identity signal 強
2. **熱門 keyword 命中** — 免費 / 付費 / 韭菜 / 賺錢 / 幹翻 全部高搜尋詞
3. **敵人 / 英雄敘事** — 讀者「站隊」轉發 = 表態
4. **TM 級用詞** — organic creator signal（行銷帳號不敢用粗話）
5. **無 CTA / 無連結 / 純情緒** — 演算法判「meaningful conversation」+ 不像導流帳號
