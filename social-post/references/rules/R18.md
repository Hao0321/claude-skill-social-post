## R18：儲存（Save）指標重視

儲存 = revisit 信號，權重僅次私訊分享。設計：明確索取物品 / reusable framework / 列點清單。戰績追蹤加儲存欄位。實證 F23 儲存 40 = mega-viral broke。

### R18 擴充：儲存量級階梯 + 觸發物 + value-prop 拉爆（6/25 466 儲存史上最高）

**權重梯**：私訊分享 > **儲存** > 分享（20x讚，R39）> 留言（5x讚）> 讚（≈0）。Save = 「現在沒空之後要回來用」的 revisit 信號 → 演算法判高價值 → broke。

**儲存量級階梯（實證）**：
| 儲存 | 觸發物 | broke |
|---|---|---|
| **466** 🏆（6/25 自動剪輯）| 清楚 value prop「丟素材自動剪+雙語字幕」 | 90.4% |
| **303**（7/20 value-prop 長文）| 清楚 value prop + 可拿走的開源 artifact | 83.8% |

| 20（6/11 抽象 claim）| 「相信我很強」 | 15.1% 鎖鐵粉 |

**拉爆儲存 4 招**：
1. **清楚 value prop > meta 故事**（R37）：6/25 466 存 vs 6/23 同工具 meta 22 存（21x 差）
2. **明確索取物**：「丟給你 / 拿去用 / 自己改」讓人按 save 記得回來
3. **reusable framework**：可截圖金句（F23「會設計製作流程的人永遠值錢」= 40 存）
4. **demo 看得到成品 > 抽象宣稱**（R36，45 vs 20 存）

**評估用法**：儲存 ≥ 22 通常 = broke 鐵粉圈訊號；史上 broke 篇儲存 ≥ 40。早期儲存會 second push 翻盤（F19 mini 1→4）。**戰績追蹤必加儲存欄位**（已 lock）。
