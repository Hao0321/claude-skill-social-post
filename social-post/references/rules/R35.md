## R35：關鍵詞留言索取 CTA = broke 鐵粉圈引擎（🏆 6/7 實證，最強 CTA）

**「留言『X』我傳給你」= 最強留言驅動 + 索取 funnel**，giveaway 篇 CTA 永久首選。

**A/B 實證（同期、同 skill 主題、同帳號）**：

| 篇 | CTA | 觀眾 | 非追蹤 | 留言 |
|---|---|---|---|---|
| **6/9 F6b giveaway** | 留言「Discord」入口留言區（公開）| **42,103** | **93.1%** 🔥🔥 | **959** 🏆 |
| 6/7 F21「不是 ComfyUI」 | 留言「自動化」我傳給你（DM）| 10,966 | 82.5% | 323 |
| 6/8 F6b 串燒 Reel | 自己去 GitHub 領 | 943 | 16% | 26 |

→ 留言關鍵詞 vs 去 GitHub = **觀眾 11.6x / 非追蹤 5x / 留言 12x**；公開 link（6/9）> DM（6/7）> 去 GitHub（6/8）。

**⚠️ R35 是 FB-native，不可直接外推全球 IG 短劇（8/9 Case 46，n=1）**：同一段繁中 caption、同一個「留言『我要』」CTA，IG 拿 61,357 觀看卻只有 24 留言；FB 只拿 5,602 觀看卻有 211 留言。→ IG 短劇主 CTA 應是追蹤下一集；skill 索取 keyword 留給 FB 或獨立幕後文。面板合併呈現不代表 FB 留言會替 IG 排名加分。

**機制**：
1. 關鍵詞留言 = 最低摩擦動作（打一個詞）→ 大量留言
2. 留言 = 5x 演算法權重（R16）→ 323 留言堆爆 → 演算法判「爆點討論」→ broke 鐵粉圈
3. 你私訊每個留言者派發 → 索取 funnel → Line 群（R7 真 KPI）
4. vs「去 GitHub 領 / 連結在下方」= 高摩擦（離開 app）+ 零留言 trigger + 連結降權（R25）= 直接死

**鐵則**：
- CTA 用「還沒領取的，留言『關鍵詞』，我傳給你」，關鍵詞短好打（自動化 / 我要 / +1）
- **絕不用「去 GitHub 領 / 連結在下方」**（R25 + 摩擦 + 零留言三重死）
- 跟 F26「要不要免費送」開放問句互補（F26 蒐集需求測水溫，R35 直接派發收割）
- 適用：F21 ship 答疑 / F15 mini / F26 後續推出 / 任何 giveaway 篇

### ⚠️ 規模天花板 + 安全 fallback（6/8 實證，血淚）

R35 太成功會反噬 ── 6/7 那篇 323 留言「自動化」→ 要私訊 323 人 → **FB 判私訊異常 → 私訊功能被限制（封號前兆）**。鐵粉 Susan Fu 親身警告「要小心被封號，藍勾勾先用起來」。

**scaling 派發協定**（6/9 翻轉：公開 link 自助 = broke giveaway 最優預設）：

| 場景 | 派發方式 |
|---|---|
| **預設（broke giveaway）** | **公開 link 自助**：link 丟「作者精選留言」，CTA「留言『關鍵詞』，入口在留言區自己拿」← 6/9 實證 **959 留言 / 93.1% / mega 42K**，無 DM 天花板 + account-safe |
| 小量 < 50 + 要 Line 群高觸轉化 | 手動私訊派發（轉化最深，但有 DM 天花板 + 封號風險）|
| 已被私訊限制 | 一律公開 link + F24 限制說明（見 Case 29）|

**🏆 關鍵翻轉**：公開 link 不是「被限制時的 fallback」，是 broke giveaway 的**最優預設** ── 6/7 DM 版 323 留言就被限制，6/9 公開版 **959 留言零限制 + mega-viral 42K**。DM 版只在小量高觸時用。

**封號防護**：
- 開 FB 藍勾勾驗證（萬一封比較快救回）← Susan Fu 建議
- 私訊批量分散時段，短時間別狂發
- 爆量篇優先公開 link，不硬撐手動私訊（帳號是金流命脈，安全 > 一時轉化）

**月配額**：無限（是 CTA 不是公式，每次有東西送都可用）。

**⚠️ 第二條 broke 路徑（cross-ref R39）**：keyword CTA 不是唯一解。內容是具體 demo / 第三方戰績 / 清楚 value prop 時，改用**反摩擦 CTA**（「拿去用就好，不用留言跟我要，順手點星」），靠分享自己帶 broke、留言可低 → 見 R39。delegation（CTA 改派具名團隊解 1對1 bottleneck，Case 35 工坊使者 30.5%）為第三條 scale 路徑。
