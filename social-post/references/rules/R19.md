## R19：Threads 轉發權重 + Keyword 機制

**Thread ≠ FB axis**：FB 最強 = 私訊分享；**Thread 最強 = 轉發 + keyword detection**。

Thread viral：F19 立場宣言 + 熱門 keyword ≥ 2（免費/付費/韭菜/賺錢/幹翻）+ 敵人英雄敘事 + 無連結 + **1 段不換行 60-150 字 + 「！」≤ 2 個**。

**雙 brand**：@lo.jain.hao FB（F6b → Line 群）/ @hao0321_studio Thread（F19 → 追蹤）。內容不交叉。

### R19 擴充：stance 綁具體 artifact 破天花板 + 跨平台公式禁用清單 + cross-platform momentum

**① stance 綁具體當紅 artifact（破紀錄關鍵，6/25 Case 39）**：抽象立場宣言有天花板（25/7「我免費分享技術」26 萬 / 轉發 76）；把 stance（幹掉付費課程）綁在**當下超火、超具體、超想要的 artifact**（自動剪輯 + 100 剪輯記憶，剛在 FB MEGA 38K/466 存）→ **4 天 44 萬，plateau 49.5 萬 / 轉發 1,278（前高 16.8x）**。demo>claim（R36）在 Thread 也成立。「100 個剪輯記憶」striking 具體細節比抽象「我公開技術」勾人 10 倍。
- **artifact 不必自產（7/16 Case 41 夥伴實證）**：綁第三方權威免費資源（Google ML Crash Course，免帳號零摩擦）→ 轉發 1,689 / 轉發率 0.40% 生態雙紀錄。權威 + 免費 + 打開就能用 = 轉發燃料。
- **🧪 但「借的 artifact 拉觸及，自產的 artifact 拉追蹤」（emerging，n=1 對比）**：借來的資源讀者拿完就走（價值源頭在 Google 不在你），漲粉轉化 0.24%；自產 artifact（av8d 指令包）1.63%，差約 7 倍。拉觸及誰的 artifact 都行，要漲粉綁自己做的。

**② 跨平台公式禁用清單（升到速查）**：Thread 只吃 **F19 + F7** 原生；**F4/F6b/F14/F15/F16 搬 Thread 必 die**（F4 無對立=無轉發；F6b ！！！太多+太長）。Case 12 F4 搬 Thread 只剩 25/7 爆款的 3-5% 觸及。

**③ cross-platform momentum（同 artifact 同波跨 FB→Thread 放大）**：一個 artifact 剛在 FB mega 過（需求已被儲存/分享驗證「大家想要」），同一波熱度下在 Thread 發 F19 版（stance 綁同 artifact）= 借已驗證需求 + 跨平台同波 → 不用重新賭需求，直接破紀錄。實證 Case 38+39 同週同 artifact：FB 38K/466 存 + Thread plateau 49.5 萬/轉發 1,278（各破平台紀錄）。
- 操作：artifact 先在 FB ship（R37 value-prop-lead 或 F6b）確認 mega + 高儲存 → 同週 Thread 發 F19 版 → 兩篇各守各平台公式不交叉照搬（R19 雙 brand 邊界）
- vs R24：R24 = 同純血結構可連發但每篇主題須各換（結構軸；原量化階梯已刪，見 R24）；cross-platform momentum = 同 artifact 跨平台同波借力（artifact 軸），可疊用

**④ Thread 三指標分軸讀法（分享 ≠ 轉發 ≠ 瀏覽，別混為一談）**：
- **轉發（repost）= 高承諾 identity 表態**，Thread 最深信號（比讚 5-10x）。衡量「多少人願意把你的立場原封不動掛自己名下」= 站隊深度。要拉爆轉發需 stance 綁**具體當紅 artifact**（R19①/R41），抽象 stance 有轉發天花板。
- **分享（share）= 低承諾高擴散引擎**（不掛名、只傳出去），把內容帶進陌生 feed。道德對立/情緒內容最容易被「傳給朋友看看」。
- **瀏覽 = 最淺指標**，由 keyword 主動推 + 分享擴散 + 站隊情緒共同拉動。
- **profile 判讀**：「高瀏覽 + 高分享 + **相對低轉發率**」= 擴散力強但**表態深度淺**（缺具體 artifact 錨點）；「轉發率高」= 站隊深、identity 強。實證對照 Case 39 vs Case 40：Hao plateau 49.5 萬 / 轉發率 **0.258%**（stance 綁 100 剪輯記憶）vs partner 53 萬 / 轉發率 **0.115%**（抽象 stance）→ partner 擴散贏、表態淺。**高瀏覽不等於高轉發，要拉深度看轉發率。**

**Thread CTA 軸 = 轉發（identity 表態）非留言索取**：Thread 的「CTA」是把立場綁成可表態的東西讓人轉發，keyword 留言 CTA 在 Thread 反而無效。
