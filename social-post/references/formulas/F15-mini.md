## F15 mini｜極簡開源型（5/12 F19 實證 mid-viral）🆕 v0.7.2

**骨架**（3 段 / 每段 1 句 / 零繞圈）：
```
[正向成果 hook + ！！！] X 終於開啦！！！或 X 終於 Y 了！！！

[歸功 + skill 連結] 多虧了我的 ＜skill/工具＞！！

[零摩擦 CTA] 我有開源了/已上架，歡迎自取
```

**實證**：5/12「FB內容營利終於開啦！！！」**24h 後 mid-viral**：
- 瀏覽者 814 / 讚 40 / 留言 10 / 儲存 4 / **非追蹤者 29.8%**（broke 鐵粉圈）
- 7h 後 second push 觸發（298 → 814 觀眾，2.73x）
- 純粹開源 + 索取 hook，無 meta 繞圈

**為何 work**（vs F15 完整版 1700 行 SKILL.md）：
- **meta 層數 = 1**（成果 + skill）vs F15 = 2 / V3 fail 版 = 4
- **5 秒讀懂測試**完美通過（3 句話）
- **零閱讀焦慮**（不用滑長文）
- **儲存率高**（明確「索取」行動 → 用戶按 save 記得回來）
- **正向情緒 hook**（「終於開啦」FOMO trigger）vs V3 fail 的 self-criticism 負向

**結構比較**：

| 維度 | F15 完整版 | **F15 mini** | F6b 純血 |
|---|---|---|---|
| 段數 | 5+ 段 | **3 段** | 4 段 |
| 字數 | 1500-3000 | **30-50** | 200-400 |
| meta 層數 | 2 | **1** | 2 |
| 寫作時間 | 1-2 h | **5-10 min** | 30-60 min |
| viral 機制 | knowledge curation + 內幕優越感 | **FOMO + 零摩擦 + 儲存** | 留言區拉群 |

**何時用 F15 mini vs F15 完整版**：

| 場景 | 用哪個 |
|---|---|
| skill / 工具 / repo / 課程**剛 ship** + 想快速擴散 | **F15 mini**（極簡 FOMO）|
| skill / 工具 / repo 已 ship 一陣子 + 想深度教學 | F15 完整版（長文 reusable framework）|
| 想突破鐵粉圈 + 快速 RoI | **F15 mini**（low effort high yield）|

**月配額**：F15 mini 每月 2-3 篇都 OK（不像 F6b 需嚴格 R5 主題冷卻）。

**複製度**：5/5
**平台**：FB 主、Threads 都可

**Hao 適配度極高**（⭐⭐⭐⭐⭐）：
- 寫作時間 5-10 min（最低成本）
- 完美 match「skill 開源」brand
- 雙 funnel（FB 觸及 + GitHub star + Line 群入群三路）
- Hao 14 天有 14+ 個 ship moment 可用（規則 update / 公式新增 / case study / release tag）
