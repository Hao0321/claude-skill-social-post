## F28｜第三方戰績 social proof 型（v1.0.2+，6/26 實證）🆕 works-for-others broke hook

**用途**：當你想證明「我的東西有用」── 不自誇「我很強」，秀**一個具體的、別人用你的東西做出的誇張成績**（R38 的公式落地）。

**骨架**（純 R34 ，、 + ── 分隔符，第三方戰績 + 謙卑 + 開源 giveaway）：
```
[1. 第三方具體戰績 hook（一個誇張可驗證數字）] 昨天那套＜skill/工具＞又搞出誇張成績 ── 社群夥伴拿它＜平台＞發一篇，＜誇張數字1，例：瀏覽衝 17.4 萬＞，＜誇張數字2，例：粉絲一百多變四千六百多＞
──
[2. 謙卑抬高價值] 老實說這套我沒辦法教你怎麼做，花快三個月一篇篇磨出來的直覺，寫不成 SOP
──
[3. 反賣課 giveaway] 所以我給的不是一堂課，是直接開源丟給你
──
[4. 低摩擦 CTA（R39 反摩擦路徑）] 連結放留言區拿去用就好，不用留言跟我要，覺得有用順手 GitHub 點顆星
```

**觸發時機**：有人（社群夥伴 / 學員 / 第三方）用你開源的東西做出可驗證的好成績時。

**為何 work（broke + 高分享）**：
1. **concrete > abstract**：具體可驗證數字（17.4 萬 / 400→4,600）比抽象「很多人用我變網紅」可信
2. **works-for-others > I'm great**：「它對別人也有用」比「我很厲害」shareable、心理阻力低
3. **謙卑抬高價值**（「磨三個月寫不成 SOP，所以直接開源」）= trust + giveaway 雙觸發
4. **comments ≠ broke**：靠分享自己帶 broke（分享 = 20x 權重，R39），留言可低

**實證對比**：
| | 6/11 抽象自誇（Case 33-A）| 6/26 具體第三方（Case 37）|
|---|---|---|
| 非追蹤 | 15.1% 鎖鐵粉 | **83.3% broke（~25K）** |
| 分享 | 15 | **53** 🔥 |
| 留言 | 91 | 48 |

**voice 鐵則**：純 R34 ，、 + ──，謙卑不自誇，戰績讓數字說話。

**月配額**：1-2（算 R5「社群 social proof」意圖配額；第三方戰績難得，有就用；**別自己編 / 灌水數字** = R32 假大方禁忌）。
**複製度**：4/5（需要真實第三方戰績）
**平台**：FB 主、Thread
